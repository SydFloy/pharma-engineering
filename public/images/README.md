# Image assets

Place replacement images here to be served from `/images/...`.

- `images/toppers/` — hero and page-header background images (pharmaceutical cleanrooms, HVAC/AHU, engineers, control panels, BMS/SCADA).
- `images/projects/` — project and case study photography.
- `images/team/` — team member photos.

Example:
- `/images/toppers/cleanroom-hero.jpg`
- `/images/projects/hvac-upgrade-1.jpg`

Update the corresponding `src/data/*.ts` files and the `ProjectImagePlaceholder` usages when real photography is available.
